# awesome-mcp-brasil

[![Awesome](https://awesome.re/badge-flat.svg)](https://awesome.re) ![entradas](https://img.shields.io/badge/entradas-87-blue?style=flat-square) ![no registro oficial](https://img.shields.io/badge/no_registro_oficial-12-blue?style=flat-square) ![sem chave](https://img.shields.io/badge/sem_chave-38-brightgreen?style=flat-square) [![verificação semanal](https://img.shields.io/github/actions/workflow/status/daniel-filius/awesome-mcp-brasil/verify.yml?style=flat-square&label=verifica%C3%A7%C3%A3o%20semanal)](https://github.com/daniel-filius/awesome-mcp-brasil/actions/workflows/verify.yml) [![stars](https://img.shields.io/github/stars/daniel-filius/awesome-mcp-brasil?style=flat-square)](https://github.com/daniel-filius/awesome-mcp-brasil/stargazers)

Lista **curada e auto-verificada** de servidores MCP (Model Context Protocol) e skills de agente **brasileiros** — dados públicos, fiscal, jurídico, SaaS BR, Pix, eleições — para usar no Claude Code, Claude Desktop, Cursor, Windsurf, Gemini CLI ou qualquer cliente MCP. Cada entrada mostra stars e último commit (ao vivo), tipo de pacote, se **exige conta/chave** e se está no [registro oficial do MCP](https://registry.modelcontextprotocol.io). Uma GitHub Action roda toda semana, checa link morto e repositório arquivado e abre um PR com a tabela regenerada — o hub não fica com link quebrado.

> Fonte única: [`data/servers.yaml`](data/servers.yaml) · README gerado em 2026-10-05 por `scripts/build_readme.py`. **Não edite o README à mão** — edite o YAML ou [abra uma issue](https://github.com/daniel-filius/awesome-mcp-brasil/issues/new?template=adicionar-servidor.yml).

## Como instalar um servidor MCP no Claude Code / Cursor

Três passos valem para qualquer entrada desta lista:

1. **Olhe a coluna Pacote** — ela diz o comando: ![npm](https://img.shields.io/badge/npm-CB3837?style=flat-square&logo=npm&logoColor=white) → `npx -y <pacote>` · ![PyPI](https://img.shields.io/badge/PyPI-3775A9?style=flat-square&logo=pypi&logoColor=white) → `uvx <pacote>` (ou `pip install`) · ![OCI](https://img.shields.io/badge/OCI-2496ED?style=flat-square&logo=docker&logoColor=white) → `docker run -i --rm <imagem>` · ![remoto](https://img.shields.io/badge/remoto-0F766E?style=flat-square) → URL HTTP/SSE, nada a instalar · ![só git](https://img.shields.io/badge/só_git-6E7781?style=flat-square&logo=git&logoColor=white) → `npx -y github:owner/repo` ou `uvx --from git+https://github.com/owner/repo <comando>` (sem pacote publicado; veja o README do projeto).
2. **Olhe a coluna Chave** — ![chave: não](https://img.shields.io/badge/chave-não-brightgreen?style=flat-square) funciona na hora; ![chave: sim](https://img.shields.io/badge/chave-sim-orange?style=flat-square) pede token/conta em variável de ambiente (`-e CHAVE=...` ou bloco `env`).
3. **Registre no seu cliente** com um dos exemplos abaixo, reinicie o cliente e confira com `claude mcp list` (Claude Code) ou no painel de MCP do editor.

**Claude Code** (terminal — escopo `-s user` deixa disponível em todos os projetos):

```bash
# npm publicado (stdio)
claude mcp add -s user ibge-br -- npx -y ibge-br-mcp
# PyPI publicado (stdio)
claude mcp add -s user fiscal-brasil -- uvx mcp-fiscal-brasil
# só git, sem pacote publicado (npm direto do GitHub)
claude mcp add -s user kiwify -e KIWIFY_CLIENT_ID=... -e KIWIFY_CLIENT_SECRET=... -- npx -y github:pauloFroes/mcp-kiwify
# só git, Python (uvx direto do GitHub)
claude mcp add -s user taco -- uvx --from git+https://github.com/matheusbuniotto/taco-mcp.git taco-mcp
# imagem Docker/OCI (stdio dentro do container)
claude mcp add -s user mcp-brasil -- docker run -i --rm ghcr.io/<owner>/<imagem>
# servidor remoto (Streamable HTTP)
claude mcp add -s user --transport http ibge-remoto https://gateway.pipeworx.io/ibge-br/mcp
```

**Cursor, Claude Desktop, Windsurf, VS Code (Copilot), Gemini CLI** — mesmo JSON, arquivo diferente:

| Cliente | Arquivo |
|---|---|
| Cursor | `~/.cursor/mcp.json` (global) ou `.cursor/mcp.json` (projeto) |
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) · `%APPDATA%\Claude\claude_desktop_config.json` (Windows) |
| Windsurf | `~/.codeium/windsurf/mcp_config.json` |
| VS Code (Copilot) | `.vscode/mcp.json` — a chave raiz é `servers` em vez de `mcpServers` |
| Gemini CLI | `~/.gemini/settings.json`, dentro de `mcpServers` |

```json
{
  "mcpServers": {
    "ibge-br":       { "command": "npx", "args": ["-y", "ibge-br-mcp"] },
    "fiscal-brasil": { "command": "uvx", "args": ["mcp-fiscal-brasil"] },
    "nota-fiscal":   { "command": "npx", "args": ["-y", "@rodrigodocarmo/mcp-nota-fiscal"],
                       "env": { "NUVEM_FISCAL_TOKEN": "seu-token" } },
    "ibge-remoto":   { "url": "https://gateway.pipeworx.io/ibge-br/mcp" }
  }
}
```

**Deu erro?** Os três motivos mais comuns: (1) `npx`/`uvx` não está no PATH do cliente gráfico — instale Node ≥ 18 / `uv` e reinicie o app; (2) servidor ![chave: sim](https://img.shields.io/badge/chave-sim-orange?style=flat-square) sem a variável de ambiente — confira o nome exato no README do projeto; (3) entrada ![só git](https://img.shields.io/badge/só_git-6E7781?style=flat-square&logo=git&logoColor=white) cujo README manda clonar e rodar `python main.py` — aí o `command` é o caminho do Python do venv e `args` o caminho do script.

Guia oficial em português: [Claude Code — MCP](https://code.claude.com/docs/pt/mcp). Quer publicar o seu servidor para que ele apareça com ![registro: sim](https://img.shields.io/badge/registro-sim-blue?style=flat-square)? Veja o [registro oficial do MCP](https://registry.modelcontextprotocol.io) e depois [abra uma issue](https://github.com/daniel-filius/awesome-mcp-brasil/issues/new?template=adicionar-servidor.yml) aqui.

## Como contribuir

1. **Sem escrever código:** [abra uma issue "Adicionar servidor"](https://github.com/daniel-filius/awesome-mcp-brasil/issues/new?template=adicionar-servidor.yml) com URL, categoria, descrição, tipo de pacote e se exige chave.
2. **Por PR:** edite [`data/servers.yaml`](data/servers.yaml) (nunca o README), rode `python3 scripts/build_readme.py && python3 -m unittest discover tests` e envie.
3. **Critérios:** projeto brasileiro ou focado em dados/plataformas do Brasil; repositório público, não arquivado, com README que explique como instalar; servidores MCP, skills de agente ou guias em pt-BR. Sem links de afiliado, sem projetos vazios (README só com título).
4. **Remoção:** entradas com link morto ou repositório arquivado por 2 verificações semanais seguidas saem da lista (ficam no histórico do git).

Projetos irmãos deste hub: [apuracao-2026-mcp](https://github.com/daniel-filius/apuracao-2026-mcp) (eleições 2026 via TSE).
